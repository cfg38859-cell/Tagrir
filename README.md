# ویرایشگر تقریر — ساخت APK و EXE با GitHub

## مراحل
1. در github.com یک مخزن (Repository) جدید بسازید (مثلاً taqrir-editor).
2. همهٔ فایل‌های این پوشه را در آن آپلود کنید (Add file → Upload files).
   مهم: پوشهٔ مخفی `.github` هم باید آپلود شود. اگر در آپلود مرورگر دیده نشد، از GitHub Desktop یا git استفاده کنید.
3. به تب Actions بروید → «Build APK and EXE» → Run workflow.
4. بعد از ۵ تا ۱۰ دقیقه، در پایین صفحهٔ همان اجرا، بخش Artifacts دو فایل هست:
   - TaqrirEditor-apk  (فایل apk)
   - TaqrirEditor-exe  (فایل exe پرتابل ویندوز)
5. برای انتشار با لینک دانلود دائمی: یک Release با تگ `v1.0.0` بسازید؛ فایل‌ها خودکار ضمیمه می‌شوند.

## نکات
- APK از نوع debug است؛ مستقیم روی گوشی نصب می‌شود (نصب از منابع ناشناس را فعال کنید). برای گوگل‌پلی باید امضای release ساخته شود.
- ویندوز ممکن است هشدار SmartScreen بدهد (چون فایل امضا نشده است): More info → Run anyway.
- در اندروید خروجی Word/HTML/TXT از طریق منوی اشتراک‌گذاری ذخیره می‌شود؛ خروجی PDF فقط در نسخهٔ ویندوز/مرورگر کار می‌کند.
- ذخیرهٔ خودکار در حافظهٔ خود برنامه انجام می‌شود.
